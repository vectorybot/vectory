* Current State
- Player CLI (=bin/vectory/=) is the active player entrypoint.
- New public prediction flow uses a native Vectory wallet, a signed canonical prediction payload, and a SHA-256 proof-of-work nonce.
- =vectory predict= derives the active round from Supabase for now; rounds are still manually announced.
- =vectory predict= prints tweet text by default for manual copy/paste posting.
- =vectory predict --post= uses Twitter API credentials from either =config.yaml= or =TWITTER_*= environment variables.
- Legacy hidden commit/reveal commands remain for old rounds, but new public prediction work should use =wallet= and =predict=.
